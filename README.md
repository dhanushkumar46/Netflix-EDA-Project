Netflix Exploratory Data Analysis (EDA)

Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Analysis Performed
1. Dataset Structural Overview
2. Missing Value Analysis
3. Summary Statistics
4. Categorical Data Analysis
5. Data Visualization
6. Final Findings

Visualizations
- Release Year Distribution
- Movies vs TV Shows
- Content Type Percentage
- Top 10 Countries
- Movie Duration Distribution
- Content Rating Distribution

Dataset
[Kaggle Netflix Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## Conclusion
This project helped me understand real-world data analysis, identify missing values, explore patterns, and visualize insights using Python.
